
# Activity 5 – AI Tools: Prompt Improvement

## Activity Description

This activity explored how artificial intelligence tools can generate responses based on user instructions or prompts. It involved comparing an original prompt, "How to make chocolate chip cookies," with an improved and more detailed prompt to examine how the quality and specificity of instructions influence AI-generated outputs.

## What Have I Learned?

- I learned the importance of prompt clarity, specificity, context, and organization when interacting with AI tools.
- I developed skills in prompt engineering, evaluating AI-generated responses, and improving instructions to achieve more useful results.
- One challenge was identifying which details were necessary to make the original prompt more effective. I addressed this by adding relevant instructions, context, and expected output details.
- In the future, I can apply prompt improvement techniques to academic research, information gathering, brainstorming, and creating educational materials. I also aim to use AI responsibly and evaluate its responses critically.
